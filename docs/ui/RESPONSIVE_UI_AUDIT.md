# UniTap 2.0 Responsive UI Audit Matrix

## 1. Executive Summary
This audit inspects the UniTap 2.0 application layout and components across viewports from **320px to 1440px** (focusing on narrow mobile 320px, 344px, 360px, 375px, 390px, 412px, 440px, tablet 768px, and desktop).
The audit identifies layout clipping, horizontal overflow, crowded multi-action cards, fixed max-widths, and header collisions on narrow viewports.

---

## 2. Responsive UI Audit Matrix

| Page / Component | UI Section | Viewport Affected | Problem Description | Root Cause in CSS / Layout | Proposed Fix | Shared Component |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| `src/components/ui/UniPageHeader.vue` | Header Title & Actions | $\le 390\text{px}$ (320px–375px) | Title "Offline Financial Reports" and long headers get clipped with ellipsis or collide with trailing buttons | `.uni-header-title` has `white-space: nowrap; overflow: hidden; text-overflow: ellipsis;` and `.uni-header-inner` has fixed `max-width: 580px` | Allow natural wrapping (`white-space: normal; word-break: break-word`), dynamic font sizing (`clamp(18px, 5vw, 22px)`), fluid container `max-width: 1200px`, and wrap trailing actions on narrow viewports | `UniPageHeader.vue` |
| `src/views/ReportsPage.vue` | Header & Action buttons | $\le 360\text{px}$ | Title abbreviated; Export and Print actions squeeze title | Action buttons in single flex row competing with 26-character title in narrow viewport | Allow header flex-wrapping; ensure title wraps cleanly without clipping; preserve compact icon-only Export and Print | `ReportsPage.vue`, `UniPageHeader.vue` |
| `src/views/ReportsPage.vue` | Filter Bar (`.filter-top-row`) | $\le 360\text{px}$ | Long academic period label (e.g. "1st Semester • A.Y. 2026–2027") collides with Filters button | `.filter-top-row` uses `nowrap` flex without adaptive wrapping | Allow `.filter-top-row` to flex-wrap gracefully (`gap: 8px`), keeping period on line 1 and Filters button accessible | `ReportsPage.vue` |
| `src/components/ui/UniKpiCarousel.vue` | KPI Cards & Amounts | $\le 360\text{px}$ (320px–344px) | Large currency strings (e.g. `₱1,250,500.00`) can clip inside 75% card | `.card-amount` fixed `font-size: 26px;` with static padding | Use `font-size: clamp(20px, 5.5vw, 26px)` with `min-width: 0` and tabular numeric spacing | `UniKpiCarousel.vue` |
| `src/views/settings/EventCategoriesPage.vue` | Category Cards (`.category-card`) | $\le 412\text{px}$ (320px–390px) | Card layout is heavily crowded: category name, code badge, status pill, description, linked events, sort order, and 3 action buttons forced into 1 row | `.category-card` is a horizontal flex container with fixed 32px action buttons taking ~110px, leaving only ~160px for multiline content | Convert to `UniExpandableRow.vue`: collapsed state shows name, code, status, linked count; expanded state reveals description, metadata, and full-width touch buttons (`[ Edit ] [ Deactivate ] [ Delete ]`) | `EventCategoriesPage.vue`, `UniExpandableRow.vue` |
| `src/views/settings/SemestersPage.vue` | Semester Cards (`.semester-card`) | $\le 412\text{px}$ (320px–390px) | Term title, academic year tag, status, dates, stats, and action buttons (`[ Edit ] [ Set as Active ]`) crowd together | `.semester-card` flex row forces ~130px action buttons beside multiline metadata | Convert to `UniExpandableRow.vue`: collapsed shows term, year, status, dates; expanded shows full details grid and dedicated action buttons (`[ Edit ] [ Set as Active ]`) | `SemestersPage.vue`, `UniExpandableRow.vue` |
| `src/components/ui/UniExpandableRow.vue` | Row Header Titles & Actions | $\le 360\text{px}$ | Title forced to truncate with ellipsis even when space exists below; action buttons in body don't wrap | `.row-title` has `white-space: nowrap`; `.body-actions` lacks `flex-wrap: wrap` | Allow title to wrap naturally (`word-break: break-word; line-height: 1.3`); add `flex-wrap: wrap` to `.body-actions` | `UniExpandableRow.vue` |
| `src/theme/custom.css` & Global Layouts | `.page-container` & `.safe-content` | $\le 359\text{px}$ & $\ge 768\text{px}$ | On 320px–344px screens, 16px/20px padding reduces content width excessively; on desktop, fixed 580px max-width artificially restricts layout | `.page-container` has `max-width: 580px;` and fixed padding | Fluid `max-width: 1200px` for desktop; responsive padding (12px at $\le 359\text{px}$, 16px default); `min-width: 0` on flex items | `custom.css`, all views |
| `src/views/settings/SectionsPage.vue` | Search & New toolbar | $\le 360\text{px}$ | Searchbar placeholder can compress or push New button off-screen | `.toolbar-row` has `nowrap` and missing `min-width: 0` on searchbar | Add `min-width: 0` to searchbar; enable responsive wrapping on $\le 360\text{px}$ | `SectionsPage.vue` |
| `src/views/StudentsPage.vue` | Header & Action button | $\le 360\text{px}$ | "Add Student" button beside title and subtitle crowds header | Single-row flex header in `UniPageHeader` | Responsive wrapping in `UniPageHeader` accommodates title and button smoothly | `StudentsPage.vue`, `UniPageHeader.vue` |
